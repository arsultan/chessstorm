# Шахматные тренажёры (diaschess88)

Статический сайт: два тренажёра, без сервера и базы данных. Работает на GitHub Pages, Netlify или любом хостинге статических файлов.

| Папка | Что это |
|---|---|
| `index.html` | Главная страница со ссылками на оба тренажёра |
| `storm/` | «Шахматный шторм»: решение позиций на время. Все книги (Вудпекер, Конотоп 2 и 3 разряд и др.) встроены в один `index.html` (~2,4 МБ) |
| `debut/` | «Дебютный справочник»: дерево ходов 76 репертуаров. `core.json` — первые 10 полуходов, `r/N.json` — глубже, по репертуарам; `meta.json` — названия репертуаров, ID студий и глав Lichess |
| `tools/` | Python-скрипты, которыми собраны данные (см. ниже) |
| `data/` | Исходники: PGN Конотопа 2 и 3, решения движка и тренера, PGN дебютов, ID студий и глав |

## Как выложить на GitHub Pages
1. Загрузить содержимое этой папки в корень репозитория.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<user>.github.io/<repo>/`.

Важно: страницы нельзя открывать как файл двойным щелчком (`file://`) — справочник подгружает JSON через `fetch`. Для проверки на компьютере: `python3 -m http.server` в этой папке и открыть `http://localhost:8000`.

## Шторм
- Код доступа учеников: хранится как SHA-256 от `chstorm:` + код в теге `<script id="accessCfg">` (`{"h":"…"}`). Пустая строка `"h":""` — без кода. Новый хеш: `python3 -c "import hashlib;print(hashlib.sha256(b'chstorm:НОВЫЙКОД').hexdigest())"`.
- Панель учителя «Новый код» работает только на claude.ai (использует `claude.use('artifact')`); на обычном сайте код меняют вручную, как выше.
- Ссылка на книгу и раздел: `storm/#kn31` (книга `kn3`, позиция 1), `#kn2…`, `#wp…` и т.д.
- Прогресс, рейтинг и «Мои ошибки» хранятся в `localStorage` браузера ученика.

## Как добавить книгу в шторм (Конотоп)
Скрипты писались с абсолютными путями `/home/claude/...` — поправьте пути под себя. Нужны `python-chess` и Stockfish.
1. `tools/solve2.py SRC.pgn OUT.json PRIOR.json` — решения движком (Stockfish 16, путь `/usr/games/stockfish`).
2. `tools/import_teacher.py` — подмешать решения тренера из студии Lichess (они важнее движка).
3. `tools/build_kon.py src.json out.json id "Короткое имя" "Название книги" "Автор" rbase [teacher.json]` — собрать книгу.
4. `tools/add_book.py storm/index.html book.json id` — встроить книгу в страницу; `tools/rm_book.py` — удалить.

## Как пересобрать дебютный справочник
`tools/tree_build.py` читает PGN из `data/debuty/pgn`, `plan2.json` (порядок и стороны репертуаров), `ids2.txt` (ID студий), `chapters.json` (ID глав) и пишет `debut/meta.json`, `debut/core.json`, `debut/r/*.json`. Названия дебютов — из lichess-org/chess-openings (CC0).

Студии на Lichess (аккаунт diaschess88) сейчас закрытые: ссылки из справочника открываются только владельцу. Для учеников их нужно перевести в «по ссылке».
